A Tale of the Three Kingdoms

On Android, the game runs in your browser with the Rust WebAssembly engine. Start the Rust server on a computer using its LAN launcher.

Enter the computer's Wi-Fi IPv4 address, for example 192.168.1.23. The phone must be on the same private Wi-Fi.

Turn your phone sideways for the compact game interface. Tap to enable sound. A native Android installation is not part of this build.
