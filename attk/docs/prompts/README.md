# Generation prompt reference

Canonical prompts live here. Copy the relevant fenced text block.
Production requests, edits, correction prompts and historical briefs
remain separately labelled. Line wrapping is limited to 80 characters
without changing the words of saved prompts.

The original guide PNGs, generation seed and model version are not
archived. Reference-based prompts require the named source image; exact
pixel reproduction is not promised. New artwork does not establish
permission to sell copied underlying terrain layouts or other assets.
