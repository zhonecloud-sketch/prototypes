Clone the prototypes repository and keep rtk2/ beside the existing lib/ folder. Install Python 3, then run rtk2/start-game.bat on Windows or sh rtk2/start-game.sh on macOS/Linux. The game opens at http://localhost:8080/rtk2/. Editable source, artwork, existing AI profiles, reports and tests are included. Node.js is needed only for development and explicit training, not to play. Routine updates are delivered through GitHub; ZIP exports require an explicit request.
